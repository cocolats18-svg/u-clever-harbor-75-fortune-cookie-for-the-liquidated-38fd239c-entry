A single original fortune cookie line for a crypto trader who has just been liquidated — rueful, warm, and funny about the loss, written to be read at 3am with an empty wallet and a stubborn sense of humour.

## Run it

```sh
node main.ts
```

The program writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): at most 20 words, 1 to 160 characters, plain UTF-8 text. Node 22+ stdlib only, no network, no randomness — the same line every run.
